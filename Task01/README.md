# Описание структуры файлов данных (Task01)

Данная директория содержит исходные файлы набора данных (dataset), а также сформированные файлы с результатами обработки и описанием выполнения.

## Исходные файлы данных:
* **links.csv** — идентификаторы фильмов в различных внешних сервисах (IMDb, TMDb).
* **movies.csv** — список фильмов с указанием идентификатора, названия и жанров.
* **ratings.csv** — оценки фильмов пользователями (userId, movieId, rating, timestamp).
* **tags.csv** — пользовательские теги, присвоенные фильмам (userId, movieId, tag, timestamp).

## Файлы выполнения задания:
* **ratings_count.txt** — результат расчета минимального и максимального userId и их строк.
* **sqlite.txt** — SQL-запрос/команды для SQLite.
