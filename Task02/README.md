# Лабораторная работа 2. Подготовка скриптов для создания таблиц и добавления данных

## Требования к окружению

Для корректной работы скрипта `db_init.bat` в системе должны быть установлены и доступны через переменную окружения `PATH`:

* **Python 3** (команда `python3`) — используется для запуска утилиты `make_db_init.py`.
* **SQLite 3** (команда `sqlite3`) — используется для создания базы данных и выполнения сгенерированного SQL-скрипта `db_init.sql`.

## Запуск

Перейдите в каталог `Task02` и выполните:

```bash
./db_init.bat
```

В результате работы скрипта будет сформирован файл `db_init.sql` и создана база данных `movies_rating.db` с таблицами `movies`, `ratings`, `tags` и `users`.
